# Creator Overview — Andrei Zelenco

> Working reference for skill authors. The user-facing distillation of this content lives in the skill's `Attribution & Status` section and in the plugin's `extras/ATTRIBUTION.md`.

## Identity

- **Name:** Andrei Zelenco
- **Background:** Landscape architect → 3D artist. Brought parametric-design thinking (Rhino + Grasshopper, Autodesk Inventor) into Substance Designer starting around 2017.
- **Notable past work:** projects with Nike (referenced in his profile material).

## Pedagogical signature

A distinctly **mathematical / systems-oriented** approach to Substance Designer. Where most SD educators teach the tool as a node-recipe craft, Andrei teaches it as visual programming — emphasizing FX-Map, Pixel Processor, math expressions, and the iteration / feedback constructs that turn a node graph into a tiny program.

Common topics:
- FX-Map (his most extensive YouTube series)
- Pixel Processor (custom node creation, 2D simulation)
- Math expressions (sine, vector ops, sampling)
- While Loop / Iterate (procedural feedback)
- Vector field equations applied to cloth / fabric
- Sine and Fourier patterns
- Reaction-diffusion models
- 2D fluid simulation
- Parametric 3D modeling within Substance Designer

## License posture

Andrei's free YouTube tutorials and articles do not carry an explicit license declaration. This skill treats them as publicly broadcast educational content under the following discipline:

1. **Per-paragraph citation** — every technique-specific paragraph in this skill's references and SKILL.md ends with `*Source: Andrei Zelenco — <video title or article> — <URL>*`.
2. **Paraphrase, do not republish** — transcripts in `sources/transcripts/` are working notes for skill authors. The user-facing references are paraphrased summaries with citations, not transcript copies.
3. **Refer paid questions** — if a user asks about a topic covered only in paid material, point them to the Gumroad page; do not synthesize an answer from material we don't have rights to.
4. **Removal on request** — issues opened at https://github.com/kukoshock/3d-ta-plugins/issues by the creator (or representative) take priority over any in-flight content.
